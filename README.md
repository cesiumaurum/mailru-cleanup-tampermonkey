# Mail.ru без баннеров и новостной ленты

Пользовательский скрипт для Tampermonkey. На главной Mail.ru оставляет карточку почты, строку поиска и верхнее меню. В веб-почте скрывает рекламное место над кнопками открытого письма, в том числе когда объявление появляется с задержкой или сменяется другим.

## Установка

1. Установите [Tampermonkey с официального сайта](https://www.tampermonkey.net/).
2. Нажмите **[Установить скрипт](https://raw.githubusercontent.com/cesiumaurum/mailru-cleanup-tampermonkey/main/mail-ru.user.js)** в браузере с Tampermonkey. Tampermonkey покажет страницу установки. Нажмите **Установить** или **Перезаписать**, если у вас уже есть более ранняя версия.
3. Обновите вкладку Mail.ru. Скрипт будет работать и при открытии следующих писем.

Если браузер просто показывает исходный код, скопируйте его в **Tampermonkey → Создать новый скрипт**, замените шаблон и сохраните. Чтобы вернуть обычный вид сайта, выключите скрипт в панели Tampermonkey и обновите страницу.

## Что изменится

- **На главной** исчезают новости, Дзен и виджеты. Если Mail не показывает стандартную строку поиска, скрипт добавляет строку поиска Яндекса. Если карточка почты недоступна, появляются прямые ссылки «Входящие» и «Написать письмо».
- **В открытом письме** скрипт автоматически скрывает рекламный контейнер над панелью действий. Ссылки и карточки товаров, которые отправитель включил в само письмо, могут оставаться видимыми.
- **В меню Tampermonkey** на главной есть команда «Проверить очистку главной», а в почте — «Скрыть баннер над письмом» для ручного выбора, если вёрстка сайта изменилась.

## Область действия и приватность

Скрипт запускается на `mail.ru`, `www.mail.ru` и `e.mail.ru`. Он меняет отображение страницы в браузере. Скрытый рекламный блок всё ещё может выполнить сетевой запрос. Скрипт не отправляет содержимое писем на сторонний сервер, не подключает внешние библиотеки и не меняет настройки компьютера. Поиск через добавленную строку отправляет введённый запрос Яндексу при нажатии «Найти».

Версия 1.8.0 проверялась в настольном Chrome. При изменениях интерфейса Mail правила могут потребовать обновления. Для сообщения о пропущенном баннере достаточно указать версию скрипта, браузер и положение баннера. Содержание письма и персональные данные для этого не нужны.
